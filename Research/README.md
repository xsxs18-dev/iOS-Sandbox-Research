# Real research artifacts

This directory contains no precomputed device observations. Generate sessions on a device you own, export JSON and Markdown, and preserve raw evidence before annotating a working copy.

Use the ignored `Private/` child for local work if useful. Git ignore is not encryption: use appropriate local storage and access controls. Review exports for container identifiers, signing metadata and researcher notes before committing or sharing them. Do not commit credentials, provisioning profiles or personal data.

Record the app commit, device/OS/build, signing setup, exact procedure, manual lock timing, repeatability and interpretation. Separate observations from hypotheses. Unexpected behavior remains `NEEDS_REVIEW` until independently reproduced and validated.
