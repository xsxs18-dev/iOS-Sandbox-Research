# Example reports

No fabricated iPhone research report is included. The app creates JSON and Markdown from the operations it actually executes. Use **Run Safe Research Suite**, then **Export JSON & Markdown** to obtain a real report.

Unit tests contain explicitly synthetic fixtures for testing software behavior. They are not examples of iOS security results and are never shipped as preloaded app evidence. Screenshots and reports may be added only with their true source, device context and appropriate redaction. Any future synthetic illustration must be conspicuously labeled synthetic throughout.
